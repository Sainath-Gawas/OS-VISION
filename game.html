Welcome, System Administrator. Files are arriving at rapid speeds. Your task is to select the most efficient allocation algorithm to store them on the physical disk.

RULES OF ENGAGEMENT:

  • Objective: Reach 300 points before the 60-second timer expires!
  • Contiguous (1): Best for speed (+15 pts). Needs an unbroken line of empty blocks. Fails if memory is fragmented.
  • Linked (2): Flexible but slower (+12 pts). Scatters blocks into any free space.
  • Indexed (3): Highly efficient for gaps (+20 pts). Scatters data but requires 1 extra block to store the 'Index Map'.

WARNINGS & STRIKES:

  • Dynamic Deletion: Old files will occasionally be purged, leaving fragmented "gaps" in the disk. Adapt your strategy!
  • What is a Strike? If you attempt an allocation that fails (e.g., selecting Contiguous when the space is too fragmented, or running out of disk space), you receive a Strike and lose points.
  • 3 Strikes = GAME OVER (SYSTEM FAILURE).
